# Research Questions

中心の問いは、自然言語の標準仕様をLean 4で形式化することで、通常のテストでは見つけにくい矛盾、曖昧さ、不完全な条件、実装との不一致を発見できるか、である。

初期PoCでは次の観測を成果として扱う。

1. 要件から導く不変条件を、任意の操作列について証明できるか。
2. 証明に必要な前提のうち、仕様の明文、外部規格への依存、モデルの選択はどれか。
3. MUST、SHOULD、MAYを混同せず、仕様が許す実装の幅を記述できるか。
4. 成立しない候補性質を有限の再現例で否定し、その原因を仕様・実装・モデルに切り分けられるか。
5. 独立した実装をJSON Oracleと比較し、差異を縮小できるか。
6. AIが生成したモデル・証明のうち、Leanが拒否する誤りと、Leanだけでは検出できない仕様の誤読は何か。

コード量・定理数は研究成果の代理指標にしない。有限テストの成功、全入力に対する定理、原仕様への忠実性、実ネットワーク／EVMでの検証を別々に報告する。AI支援は本PoCの作成方法であり、自動化の成功率・工数・人間との比較を測定した実験ではない。
