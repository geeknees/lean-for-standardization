# 証明と検証の限界

## 共通

Leanが検証するのは形式モデルに書かれた命題であり、自然言語仕様との同値性ではない。仕様の誤読、抜け落ちた条件、モデルが厳しすぎることは、カーネルによる証明成功だけでは検出できない。対応表、独立した実装、境界例、人間のレビューを組み合わせる。

任意の有限列に関する安全性の証明と、有限範囲の生成テストを区別する。活性・停止時間・最適な接続性能は証明していない。性能測定、AI自動化の成功率、人間による形式化との比較実験も未実施である。

標準仕様はいずれもDraftであり、保存した版にのみ結果を適用する。JSON CLIは研究用の入出力形式で、規格の公式APIではない。原文保存のハッシュは改変検知に使うもので、自然言語の解釈の正しさを保証しない。

## Happy Eyeballs

- 単一サービスのTCP/TLS接続を対象にし、IPv6を優先する。候補内のアドレス順は外部から与えたRFC 6724順と仮定する。
- A、AAAA、HTTPSの応答、アドレスヒント、Resolution Delay、接続開始間隔、TCP完了、TLS開始、成功、失敗、キャンセルを扱う。
- QUIC、0-RTT、ALPN、複数サービス優先度、完全なDNSエイリアス探索、DNS TTL、NAT64、キャッシュ、実ソケットは対象外。
- 接続試行間隔は固定値。§6.1のTCP進捗後に次回試行タイマーを調整するSHOULDは未実装であり、10ms下限の証明からその準拠性は導かない。
- 時間は単調な自然数ミリ秒。イベントは逐次処理し、同時のコールバックは任意の順に線形化する。整数桁あふれはモデル化しない。
- 接続開始は外部スケジューラのイベントであり、時間が進むだけでは必ず開始するとは限らない。任意列での安全性は、タイマーの公平な実行やDNS到着を仮定せず証明できるが、成功の保証にはそれらに加えて到達可能な候補、TLS成功、十分な資源が必要になる。
- セキュリティ条件は固定Configで表現する。DNSの暗号学的な真正性、ECHの処理、TLS実装の正しさを証明しない。
- 有効性述語はこのPoCの安全性条件を集めたもの。ドラフト全要件への準拠を意味しない。

## ERC-8004

- Identityの登録・所有権移転・token approval・owner別operator・wallet関連付け／解除、Reputationのfeedback投稿、Validationのrequest／responseを扱う。
- アドレス、agentId、requestHashは自然数の抽象識別子。EVMでは不可能な呼出元ゼロ、アドレスのビット幅、ハッシュ衝突等は別の環境条件として扱う。
- wallet署名の正当性をBoolean入力へ抽象化する。EIP-712／ERC-1271検証、期限、domain separator、リプレイ耐性は証明しない。
- ERC-721の承認を必要な範囲だけ表現し、safeTransferの受取コールバック、再入、gas、EVM revert実装、proxy upgrade、storage layout、URI・metadata更新を証明しない。
- feedback取消、応答追加、集約、オフチェーン情報の可用性、URI／ファイルhash、validationタグ／集約は未実装。保存するイベントも観測用の射影であり、ABIログ全体との同値性は主張しない。
- 拒否時不変の定理は抽象 `step` の意味論である。Solidityのトランザクション原子性そのものの証明ではない。
- 権限が正しく管理されても、評判の真実性、Sybil耐性、同一主体の複数アドレス検出、Validatorの判断の正しさ、経済的なインセンティブは保証されない。

## 実装比較・CI

Happy Eyeballsは[Mozillaの固定状態機械](mozilla-comparison.md)と17入力列を比較し、13本一致・4本の差を確認した。接続開始・勝者・キャンセルの全prefixが対象で、実ネットワーク、TLS開始、DNSエラー／更新、複数service group、QUICは対象外。Mozillaの宣言版`-02`とLeanの根拠版`-04`を区別する。開始指示を実際のソケット処理へ写す呼出側も検証していない。

ERC-8004は固定ソース・既存テストの調査と5ケースのローカルEVM差分実行を行い、4ケースで一致、1ケースで数値域の不一致を確認した。比較はaccept/rejectと最終状態の射影に限り、全ABI eventやrevert理由の一致は含めない。固定条件は[独立EVM比較](evm-comparison.md)を参照する。

初期PoCはPR #1でマージされ、`main`の`44ff755`で[Lean CI成功](https://github.com/geeknees/lean-for-standardization/actions/runs/39134973408)を確認した。EVM・Mozilla比較は独立したローカル実行で、通常CIに含まない。今回追加した比較のローカル成功を、この追加差分のリモートCI成功とは扱わない。上流報告は未実施。
